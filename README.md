# ReturnRate

Trust scores for e-commerce stores based on shipping and return policies.

## What we do

Score e-commerce stores on:
- Return window (days)
- Restocking fee (% charged)
- Free shipping threshold
- Shipping speed
- Customer service quality

## For Consumers

Search any store to see their "Return Rate" - should you buy from them?

## For Business

- Weekly brand reports
- Benchmark against competitors
- API access

## Tech Stack

- Next.js (frontend/API)
- Vercel (hosting)
- Supabase (database - reusing Restocka's)
- Telegram (updates bot)
